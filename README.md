기존 프롬프트는 단순히 '쉽게 써줘'였지만 지금은 독일 Leichte Sprache 규칙집(Netzwerk Leichte Sprache, 2006~)을 한국어에 맞게 옮겨 넣음
  ※ 아이디어를 얻은 Nachrichtenleicht는 한 단계 덜 단순화된 Einfache Sprache를 씀 (종속절 허용).
     그쪽은 명확한 규칙집이 없고 대략적 지침만 있어서, 규칙이 문서로 정리된 Leichte Sprache를 기준으로 삼음
  ※ 복합어 하이픈 분리, 속격/접속법 회피 같은 독일어 전용 규칙은 제외
  한 문장에 한 가지 내용, 문장마다 줄바꿈
  능동태 (~되어진다 같은 피동 회피)
  어려운 말은 바로 다음 줄에서 뜻풀이 (→ 초등학생 대상으로 바꾸면서, 본문에서 풀지 않고 누르면 뜨는 사전으로 대체)
  같은 대상은 늘 같은 단어로 (동의어로 바꾸지 않기)
  비유·관용구·사자성어·반어 금지
  약어 풀어쓰기, 큰 수·백분율은 "열 명 가운데 일곱 명"처럼
  긍정문 우선, 이중 부정 금지
3줄 요약 삭제
대상을 초등학생으로 좁힘
  ※ 실제 개인정보처리방침을 보니 생각보다 친절하게 써 있었음. 다만 초등학생 기준에서는 여전히 어려움
  ※ 개인정보 보호법 제22조의2: 만 14세 미만 아동에게는 알기 쉬운 언어로 알려야 함
  초등학교 교과서 수준의 낱말로 바꾸기
  약관에 자주 나오는 중요한 낱말(개인정보, 동의, 제3자 등)은 바꾸지 않고 남기고, 누르면 뜻이 뜨게 함
  조건과 예외(다만, ~한 경우에는)는 절대 빠뜨리지 않기
본문의 어려운 단어를 누르면 그 자리에서 뜻이 뜨는 기능 추가
대상을 다시 바꿈: 초등학생·약관 → 수행평가로 논문을 읽는 고등학생
  ※ 약관에 써 보니 오히려 가독성이 나빠짐. 표·목록이 줄글로 무너지고, 한 문장 한 줄 규칙이 목록을 길게 늘림
  ※ 결론: 이 도구는 빽빽한 줄글에서 힘을 쓰고, 이미 구조가 잡힌 글에서는 해가 됨
  ※ 논문은 줄글이고, 어려워서 초록만 읽고 넘어가는 내 문제에서 출발. 초록은 이미 요약이므로 요약이 아니라 본문을 쉽게 다시 쓰기
  학술 용어는 바꾸지 않고 남기고 누르면 뜻이 뜨게 함 (인용하고 다시 검색해야 하므로)
  단서와 한계("관련이 있다", "일부 참가자에서")는 지우거나 세게 바꾸지 않기 → 단순화가 곧 왜곡이 되는 것을 막음
  연구의 숫자는 그대로 두기 (Leichte Sprache의 "큰 수는 많은 사람처럼" 규칙은 논문에 해로워서 뺌)
  목적/방법/결과/결론 구간 표시, 영어 논문도 한국어로
붙여넣어 변환하는 칸 추가 (팝업 → 새 탭 reader.html)
  ※ 한국 논문 본문은 대부분 PDF인데, 크롬 PDF 뷰어 안에서는 확장 프로그램이 돌지 않음
실제 논문 단락(다크패턴 선행연구)으로 변환해 원문과 한 줄씩 대조함
  잘 된 점: 숫자·인용 번호 모두 유지, 없는 결과를 지어내지 않음, 선행연구 부분에 [목적] 표시를 억지로 붙이지 않음
  문제: "특히"→"다만"(연결 관계 바뀜), "증가하면서"→"그래서"(없던 인과), "모호하여"→"모호한 편"(주장 약해짐), "등" 누락
  문제: 원문에 없는 약칭(FTC)과 외래어 원어(Platform) 덧붙임, "Interface Interference"가 망가짐
  문제: 문장을 나누다 꾸밈 관계가 끊김, 핵심어 "다크패턴"이 사전에서 빠짐, 사전 뜻풀이가 본문과 어긋남
  원인: 규칙 예시로 "다만"을 적어 둠 / 원어 병기 규칙이 한국어 원문에도 적용됨 / 한 문장 한 내용 규칙이 꾸밈까지 자름
프롬프트 수정: 규칙을 문장 쓰기 / 원문의 뜻 지키기 / 용어와 이름으로 나눔
  연결어는 같은 관계로만 옮기고 새 연결어를 덧붙이지 않기, 주장을 세게도 약하게도 바꾸지 않기
  원어 병기는 다른 언어 원문일 때만, 인명·기관명은 원문 표기 그대로, 핵심 주제어는 사전에 반드시 넣기
  "쉽게 쓰는 것보다 원문의 뜻을 정확히 지키는 것이 더 중요" 명시
