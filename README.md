  ※ 아이디어를 얻은 Nachrichtenleicht는 한 단계 덜 단순화된 Einfache Sprache를 씀 (종속절 허용).
     그쪽은 명확한 규칙집이 없고 대략적 지침만 있어서, 규칙이 문서로 정리된 Leichte Sprache를 기준으로 삼음
  ※ 복합어 하이픈 분리, 속격/접속법 회피 같은 독일어 전용 규칙은 제외
